# Pendientes

Cosas que parecen faltar pero están fuera del PRD. No implementar sin decisión.

- **Logo definitivo:** el logo actual ("M" verde + Muu Track) es provisorio.
- **Variación del peso simulado:** el ±2% del PRD (unos ±8 kg en un novillo) sobre pocos días puede hacer que un animal estancado "pierda" peso en pantalla (ej: la caravana 1234 muestra −7 kg). Es coherente con el PRD, pero conviene decidir si se acota la variación para que no confunda en entrevistas.
- **Peso del gráfico (bundle):** Recharts hace que el JS pese más de 500 kB. Se puede cargar el gráfico bajo demanda si afecta la velocidad en el celular.
